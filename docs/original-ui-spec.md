# 原版 UI 与本项目设计规格

## 已实际确认

- 视觉方向：暖米色纸张背景、白色大圆角卡片、珊瑚红主操作色、深棕黑正文。
- 桌面首页：品牌顶栏；左侧文案与玩法示例；右侧约 500px 宽的创建卡片。
- 控件：胶囊语言切换、分段按钮、白色输入框、红色满宽主按钮。
- 移动端：宣传区收敛，配置卡单列，无横向滚动。
- 可见中文首页结构和文案由浏览器无障碍树实际读取，而非推测。

原站计算样式没有稳定批量导出，因此颜色、阴影和精确间距均标注为估算，不声称像素级测量。

## 响应式

- `≥860px`：双列首页，右侧固定 510px 卡片。
- `<860px`：单列配置卡，隐藏大幅宣传区。
- `≤390px`：压缩卡片内边距、字号和分段间距。
- 输入、按钮和房间卡均设置最小触控高度；长内容允许换行。
