# 未核实规则与实现假设

1. 已按原版核实规则调整为：房间满员后由房主点击“开始第 1 轮”，随后服务器统一进入短暂倒数。
2. 提交后锁定答案，不允许本轮修改。
3. 最后一人提交立即结束本轮；服务器截止时间与最后提交竞争时由 `roundId + phase` 幂等校验保证只结算一次。
4. 超时未答记为 `null`，任何未答都不能判定成功。
5. 同词用 Unicode NFC、去首尾空白后严格比较；不做近义词、大小写或语义相似度判定。
6. 揭晓持续约 2.6 秒，随后由服务端进入下一状态。
7. 默契同步率 = 全员选择一致题数 / 总题数 × 100%，这不是已确认的原版公式。
8. 房主主动退出时转移给当前玩家列表中的下一人；断线时保留席位，以支持恢复。
9. 原创题库当前 45 题，不复制原站标称 1,000 题内容。
10. 实时房间保存在服务端内存，默认 120 分钟无活动后清理。单实例可直接部署；多实例需 Redis Adapter。
